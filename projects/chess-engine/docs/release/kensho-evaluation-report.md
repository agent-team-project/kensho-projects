# Kensho Evaluation Report

This report is repo-local evidence for CHESS-040 and CHESS-041. It summarizes
the local agent-team state present during the CHESS-RELEASE-001 worker slice and
points to reproducible release commands instead of hosted project-management or
cloud telemetry.

## Reproducible Commands

- `scripts/acceptance.sh` runs the current local release gates and records
  generated evidence under `target/release-evidence/`.
- `scripts/release-transcript.sh` captures `scripts/acceptance.sh` output into
  `target/release-evidence/release-transcript.md`.
- `cargo run -p chess-engine -- baseline-tournament --games 200 --max-plies 120 --engine-depth 3`
  is the deterministic local baseline strength run needed before claiming the
  SPEC.md 95 percent baseline floor.
- `scripts/uci-gauntlet.sh` runs only when `cutechess-cli` and local opponent
  paths in `CHESS_GAUNTLET_OPPONENTS` already exist; otherwise it documents a
  skipped optional local check.

## Product Quality

The product currently has a local Rust workspace, bitboard board model, perft
fixture runner, deterministic search/evaluation, UCI loop, CLI smoke harness,
tactical micro-suite support, and a local GUI smoke path through a UCI
subprocess. The release runner exercises formatting, clippy, workspace tests,
UCI smoke, perft through depth 4, a deterministic baseline tournament smoke, GUI
smoke, and optional local gauntlet availability.

The repository should not yet claim 1800+ Elo, the full 300-position tactical
threshold, or the complete 200-game baseline floor from this report alone. Those
claims require the longer local commands above and their generated transcripts.

## Known Gaps

- `scripts/acceptance.sh` defaults to perft `--max-depth 4` for turnaround; full
  mandatory perft depths are available through `chess-engine perft-suite` but are
  intentionally called out as pending unless the longer run is executed.
- The tactical fixture directory currently has a micro-suite, not the 300+
  positions required by SPEC.md for release tactical strength claims.
- The optional cutechess gauntlet has no bundled opponents and performs no
  downloads. It skips unless local `cutechess-cli` and explicit local opponent
  engine paths are provided.
- Baseline tournament PGN and score summaries are generated under ignored
  `target/release-evidence/`; generated artifacts should be regenerated by local
  command rather than committed.
